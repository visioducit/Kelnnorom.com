1. ARCHITECTURE OVERVIEW (SPLIT-DNS TOPOLOGY)
================================================================================

To ensure maximum web application speed without compromising custom domain email
deliverability, kelnnorom.com utilizes a Split-DNS configuration:

- Web Traffic (HTTP/HTTPS):
  Routed to Vercel global edge network via apex A record (76.76.21.21)
  and CNAME record (cname.vercel-dns.com).

- Email Traffic (SMTP/IMAP/POP3):
  Routed to the authoritative cPanel mail server IP (197.210.12.85) via
  dedicated A records (mail.kelnnorom.com, webmail.kelnnorom.com) and an MX
  record pointing to mail.kelnnorom.com with priority 0.

================================================================================

Log in to your DNS Management Console (e.g. GO54 DNS Management, Cloudflare,

Name:     @ (or kelnnorom.com)

RECORD 2: WWW SUBDOMAIN (CNAME RECORD)
--------------------------------------------------------------------------------
Type:     CNAME
Name:     www
Value:    cname.vercel-dns.com.

--------------------------------------------------------------------------------
RECORD 3: MAIL HOST ADDRESS (A RECORD)
--------------------------------------------------------------------------------
Type:     A
Name:     mail
Value:    197.210.12.85  (Replace with your cPanel server IP)
TTL:      Automatic (or 14400)
Purpose:  Designates the dedicated hostname for mail.kelnnorom.com.

--------------------------------------------------------------------------------
RECORD 4: CPANEL WEBMAIL INTERFACE (A RECORD)
--------------------------------------------------------------------------------
Type:     A
Name:     webmail
Value:    197.210.12.85  (Replace with your cPanel server IP)
TTL:      Automatic (or 14400)
Purpose:  Allows access to cPanel webmail at https://webmail.kelnnorom.com:2096.

--------------------------------------------------------------------------------
RECORD 5: PRIMARY MAIL EXCHANGER (MX RECORD)
--------------------------------------------------------------------------------
Type:     MX
Name:     @ (or kelnnorom.com)
Value:    mail.kelnnorom.com
Priority: 0 (or 10)
TTL:      Automatic (or 3600)
Purpose:  Directs all inbound emails addressed to *@kelnnorom.com to your server.

--------------------------------------------------------------------------------
RECORD 6: SPF RECORD (SENDER POLICY FRAMEWORK - TXT)
--------------------------------------------------------------------------------
Type:     TXT
Name:     @ (or kelnnorom.com)
Value:    v=spf1 +a +mx +ip4:197.210.12.85 include:go54.com ~all
TTL:      Automatic (or 3600)
Purpose:  Authenticates your server IP and registrar as authorized senders.
          Prevents spoofing and prevents emails from landing in spam.

--------------------------------------------------------------------------------
RECORD 7: DKIM RECORD (CRYPTOGRAPHIC SIGNING - TXT)
--------------------------------------------------------------------------------
Type:     TXT
Name:     default._domainkey (or default._domainkey.kelnnorom.com)
Value:    v=DKIM1; k=rsa; p=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA0w9R7G6xK1mQn479b1...
TTL:      Automatic
Purpose:  Cryptographically signs all outbound emails. Copy the exact public key
          generated in cPanel under "Email Deliverability".

--------------------------------------------------------------------------------
RECORD 8: DMARC POLICY RECORD (ANTI-PHISHING / SPOOFING - TXT)
--------------------------------------------------------------------------------
Type:     TXT
Name:     _dmarc (or _dmarc.kelnnorom.com)
Value:    v=DMARC1; p=quarantine; rua=mailto:security@kelnnorom.com; pct=100; aspf=r;
TTL:      Automatic (or 3600)
Purpose:  Instructs receiving servers (Gmail, Outlook, Yahoo) to quarantine
          unauthorized senders and send aggregate health reports to security@.

3. CPANEL MAIL ROUTING & ACCOUNT PROVISIONING
================================================================================

STEP 3.1: SET "LOCAL MAIL EXCHANGER" IN CPANEL (CRITICAL)
1. Log in to your hosting cPanel dashboard.
2. Under the "Email" category, open "Email Routing".
3. Select the domain: kelnnorom.com.
4. Set the routing option explicitly to:
   [X] Local Mail Exchanger
   (Do NOT use "Automatically Detect Configuration" or "Remote Mail Exchanger".
   Because the apex A record points to Vercel, auto-detection may assume the
   domain is remote and reject incoming emails).
5. Click "Change" to save.

STEP 3.2: CREATE OFFICIAL MAILBOXES
1. In cPanel, click "Email Accounts" -> "+ Create".
2. Create the primary executive accounts:
   - kel@kelnnorom.com        (Executive Turnaround & Growth Strategy)

   - admin@kelnnorom.com      (System Administration & Operations)
3. Set high-entropy passwords (minimum 16 characters) or generate secure keys.
4. Set Storage Space: "Unlimited" (or minimum 5 GB per mailbox).
5. Click "Create".

8. TROUBLESHOOTING COMMON ISSUES
================================================================================

Issue: Inbound emails bounce with "550 No Such User Here" or "Relay Access Denied"
Fix:   Check cPanel -> Email Routing. Ensure "Local Mail Exchanger" is selected.

Issue: Emails sent to Gmail land in Spam / Junk folder
Fix:   Verify your SPF record includes the exact cPanel mail server IP address
       (+ip4:197.210.12.85) and ensure DKIM is properly configured and active.

Issue: SMTP connection timeout on port 465
Fix:   Ensure your hosting provider or local network does not block outbound
       port 465. If blocked, switch to port 587 with STARTTLS encryption.

Issue: SSL Certificate warning ("Certificate Name Mismatch")
Fix:   Ensure you use `mail.kelnnorom.com` (which has an SSL certificate issued
       via cPanel AutoSSL) rather than an unencrypted direct IP address.
